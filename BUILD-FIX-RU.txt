ИСПРАВЛЕНИЕ СБОРКИ VPN CONTROL 0.4.3

Причина предыдущей ошибки:
Android Gradle Plugin 8.12.1 требует Gradle 8.13 или новее.
GitHub Actions запускал системный Gradle 8.9, поэтому сборка падала
на применении плагина com.android.application ещё до компиляции Kotlin.

Что изменено:
1. Workflow больше не полагается на системный Gradle runner.
2. В GitHub Actions явно скачивается официальный Gradle 8.13 binary distribution.
3. В PATH добавляется именно Gradle 8.13.
4. Перед сборкой выполняется проверка версии; при неверной версии job остановится.
5. Сборка и загрузка APK используют фактическую папку проекта VPN-Control.

Как запустить:
- Распаковать архив.
- Загрузить содержимое папки VPN-Control в репозиторий GitHub, сохранив структуру.
- Убедиться, что .github/workflows/build.yml находится в корне репозитория.
- Открыть Actions и запустить Build VPN Control APK через Run workflow
  либо отправить commit в ветку main.
- После успешной сборки скачать artifact VPN-Control-0.4.3-debug.

Важно:
Этот фикс устраняет обнаруженную ошибку несовместимости Gradle 8.9/8.13.
Фактическая сборка APK в этой среде не запускалась: здесь нет Android SDK и
сетевого доступа к загрузке Gradle/Android dependencies. Успешность полной
компиляции будет подтверждена только зелёным GitHub Actions run.
