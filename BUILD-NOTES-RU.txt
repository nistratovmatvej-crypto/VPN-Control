VPN CONTROL 0.4.3 — ПОЛНЫЙ ПРОЕКТ

Что включено:
- Полный исходный Android-проект на Kotlin.
- AmneziaWG-зависимость и существующий модуль управления туннелем.
- Профили, мониторинг трафика, журнал/хранилище статистики и резервное копирование из предыдущей версии проекта.
- Workflow для GitHub Actions с Gradle 8.13 и Java 17.

Исправление сборки:
- Android Gradle Plugin 8.12.1 требует Gradle 8.13 или новее.
- Workflow проекта явно устанавливает Gradle 8.13 (не 8.9).
- В workflow есть проверка фактически запущенной версии Gradle до компиляции.

ВАЖНО ДЛЯ ТЕКУЩЕГО СПОСОБА СБОРКИ:
Если GitHub-репозиторий содержит .github/workflows/main.yml и vpn-control.zip в корне,
замените vpn-control.zip этим архивом, сохранив имя vpn-control.zip.
Внешний .github/workflows/main.yml должен извлекать vpn-control.zip и запускать Gradle 8.13.
Файл .github/workflows/build.yml внутри архива используется, если проект распаковать
непосредственно в корень отдельного репозитория; GitHub не запускает workflow,
который лежит внутри ZIP-файла.

Проверка APK:
В этой среде полноценная сборка Android APK не выполнялась. Поэтому архив нельзя
считать подтверждённо собирающимся, пока GitHub Actions не завершится успешно.
